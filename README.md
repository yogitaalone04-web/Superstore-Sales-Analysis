# Superstore Sales Analysis

## Problem Statement
Which Region, Category, and State generates the most sales in the Superstore dataset?

## Dataset
- Source: Superstore Sales Dataset
- Rows: 9,801
- Tools Used: Microsoft Excel, Python (Google Colab)

## Analysis Done
- Region-wise Sales Analysis
- Category-wise Sales Analysis
- State-wise Sales Analysis

## Key Insights
- West region leads in sales ($710,219)
- Technology is the top-selling category ($827,455)
- California is the #1 state ($446,306)

## Tools Used
- Microsoft Excel (Pivot Tables, Dashboard)
- Python (Pandas, Matplotlib)
- Google Colab

## Files
- `Superstore_Sales_Dashboard_Yogita.csv` - Dataset
- `Superstore_Sales_Dashboard_Yogita.xlsx` - Excel Dashboard
- `superstore_train.ipynb` - Python Analysis Notebook

## Dashboard
Created an Excel dashboard and Python dashboard with 3 visualizations showing sales performance across Region, Category and State.
